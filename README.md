# mekotools/signal

**Öffentliches Spiegel-Repo des MekoTools-Katalogs.** Enthält keine eigene
Software: Der Inhalt ist das fertige Container-Abbild, das hier veröffentlicht
wird, damit es **ohne Anmeldung** gezogen werden kann.

- Werkzeug: Signal (MIDI-Editor und Sequencer im Browser, ryohey/signal)
- Bezug: `docker pull ghcr.io/mekotools/signal:latest`
- Bauvorschrift: `tilllt/mekotools/mekotools-signal-8df05c22` (interne GitLab-Instanz)
- Lizenz des Werkzeugs: MIT
